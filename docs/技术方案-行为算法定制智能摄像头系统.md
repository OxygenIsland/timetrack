# 行为算法定制智能摄像头技术规格书

## 一、项目概述

### 1.1 项目背景
本项目为**A公司铝合金车间人员动态量化感知与胎位时序效能评估体系构建项目**，旨在通过部署行为算法定制智能摄像头系统，实现对车间人员的智能感知和工时统计。

### 1.2 设备基本信息
| 项目 | 内容 |
|------|------|
| 设备名称 | 行为算法定制智能摄像头 |
| 设备数量 | 1套（4台AI摄像头协同） |
| 招标范围 | 全链路设备生命周期一体化解决方案 |
| 交货地点 | A公司指定地点 |
| 交货周期 | 中标后20个工作日内 |
