# 🎯 前端需求 - 拓展需求表（二期/预留）

> 二期交付目标：在一期 4 个核心模块基础上**新增的、概念偏虚的、对接外部系统才能用上**的功能。
> 当前仅做需求储备和接口预留，**一期不交付、二期启动时间根据甲方需求确定**。

---

## 一、二期模块总览

| 模块编号 | 模块名称 | 优先级 | 来源（原始文档编号） | 触发条件 |
|---------|---------|--------|---------------------|----------|
| E1 | API 双向接口与系统对接 | P1 | ⑧⑩ + 系统集成 | 甲方明确要求对接 MES/ERP 时 |
| E2 | 数据备份管理 | P2 | ⑪ | 系统稳定性需求扩展 |
| E3 | 责任人精细化管理 | P2 | ⑦深化 | 甲方需要按"责任人"（不仅是人员）维度考核 |
| E4 | 跨摄像头追踪回放 | P2 | ⑫进阶 | 出现人员跨摄像头移动漏数投诉时 |
| E5 | 工种行为识别 | P1 | 试点方案阶段2 | 甲方推进阶段 2 时 |
| E6 | 人员定位融合 | P3 | 试点方案阶段3 | 甲方推进阶段 3 时 |

---

## 二、详细功能需求

### E1 - API 双向接口与系统对接

| 编号 | 功能项 | 详细描述 | 备注 |
|------|--------|----------|------|
| E1-01 | MES 系统对接 | 提供 API 上行接口，把工时数据推送给 MES 系统（双向） | 需甲方提供 MES 接口规范 |
| E1-02 | ERP 系统对接 | 提供 API 上行接口，把工时数据推送给 ERP 系统（双向） | 需甲方提供 ERP 接口规范 |
| E1-03 | 数据同步状态展示 | 前端展示与外部系统数据同步的状态（成功/失败/积压） | 便于运维人员监控 |
| E1-04 | 同步失败重试机制 | 支持手动触发同步失败的数据重传 | 需后端支持 |
| E1-05 | 对接参数配置 | 在前端配置外部系统的连接参数（IP、Token、接口地址等） | 与后端配合 |

---

### E2 - 数据备份管理

| 编号 | 功能项 | 详细描述 | 备注 |
|------|--------|----------|------|
| E2-01 | 手动备份触发 | 提供手动触发数据备份的入口 | 定时备份由后端/系统层实现 |
| E2-02 | 备份历史记录 | 展示历史备份记录（时间、类型、大小、状态） | |
| E2-03 | 备份状态展示 | 看板角落展示最近一次备份状态（成功/失败/未备份） | |
| E2-04 | 数据恢复入口 | 在极端情况下支持从备份恢复（高危操作，需权限控制） | |

---

### E3 - 责任人精细化管理

| 编号 | 功能项 | 详细描述 | 备注 |
|------|--------|----------|------|
| E3-01 | 责任人档案 | 维护责任人档案（如班组长、车间主任），与人员关联 | 一期仅以人员列表维度统计 |
| E3-02 | 责任人维度工时 | 按责任人维度归集工时（其下属人员工时求和） | |
| E3-03 | 责任人考核报表 | 生成责任人维度的工时考核报表 | |
| E3-04 | 责任人-人员关系维护 | 在前端维护责任人与人员的隶属关系 | |

---

### E4 - 跨摄像头追踪回放

| 编号 | 功能项 | 详细描述 | 备注 |
|------|--------|----------|------|
| E4-01 | 跨摄像头目标关联可视化 | 在 4 路视频中同时高亮同一个人员的轨迹 | 基于跨摄像头目标关联算法 |
| E4-02 | 人员移动轨迹回放 | 在量化区域示意图上回放某个人员某段时间的移动轨迹 | |
| E4-03 | 关联记录查询 | 查询同一人在不同摄像头间的切换记录 | 用于排查漏数 |
| E4-04 | 重复数据可视化 | 展示被剔除的重复识别数据（便于审核算法精度） | |

---

### E5 - 工种行为识别（阶段 2）

| 编号 | 功能项 | 详细描述 | 备注 |
|------|--------|----------|------|
| E5-01 | 工种识别模型对接 | 通过视觉算法学习识别焊接、装配、磨铣等作业行为 | 需算法侧支持 |
| E5-02 | 工种分类标签 | 在识别框/记录中展示当前识别的工种 | |
| E5-03 | 工种工时统计 | 按工种（焊工/装配工/磨铣工等）分别统计工时 | |
| E5-04 | 工种切换记录 | 记录同一人员工种切换的时间点 | |

---

### E6 - 人员定位融合（阶段 3）

| 编号 | 功能项 | 详细描述 | 备注 |
|------|--------|----------|------|
| E6-01 | 定位系统对接 | 对接人员定位系统（UWB/蓝牙等），获取人员精确位置 | 需甲方提供定位系统接口 |
| E6-02 | 行为识别融合 | 结合定位数据 + 视频数据识别每个工人的具体行为 | |
| E6-03 | 智能工时采集 | 自动采集每人每天的工时，逐步替代手工填报 | |
| E6-04 | 弃用手工表单过渡 | 提供手工填报与自动采集并行的过渡模式 | |

---

## 三、二期非功能性需求（储备）

| 编号 | 需求项 | 指标 | 备注 |
|------|--------|------|------|
| NF-09 | 双系统对接稳定性 | 外部系统对接失败不影响本地系统运行 | 容错设计 |
| NF-10 | 行为识别准确率 | 工种识别准确率 ≥85% | 待定 |
| NF-11 | 定位精度 | 人员定位精度 ≤1 米 | 待定 |
| NF-12 | 弃用手工填报过渡期 | ≥3 个月双轨并行 | 待定 |
